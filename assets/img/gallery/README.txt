Product gallery photos (side view, back, angle, etc.)

Add the photo here, for example  assets/img/gallery/azure-side.webp
Then in js/data.js add it to that product:
  gallery:[{ src:'assets/img/gallery/azure-side.webp', label:'Side view' }, { src:'assets/img/gallery/azure-back.webp', label:'Case back' }]
Thumbnails appear automatically. A photo that fails to load is hidden.
